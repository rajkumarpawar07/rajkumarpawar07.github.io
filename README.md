A clean, dark-themed, high-performance personal portfolio showcasing my engineering projects, AI/RAG architectures, professional work experience, and cloud certifications.

---

## ✨ Features

- ⚡ **High Performance & 60+ FPS**: Built with Vite 6, React 18, and custom canvas-optimized interactive effects.
- 🤖 **AI & RAG Showcase**: Highlights Agentic AI architectures, multi-modal search engines, and enterprise RAG deployments.
- 🕒 **Time-Based Media**: Dynamic profile video playback changing seamlessly based on India Standard Time (IST).
- 📜 **Interactive Experience & Certifications**: Detailed breakdown of work experience at Accenture & Argan, complete with 10+ Google Cloud & Azure certifications.
- 📱 **Fully Responsive**: Optimized side-by-side header layouts tailored for both mobile devices and desktop displays.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, React Router v6, React Icons
- **Styling**: Modern Vanilla CSS, CSS Variables, Hardware Acceleration
- **Build Tooling**: Vite 6, Rollup (Manual Chunk Splitting), ESBuild
- **CI/CD & Hosting**: GitHub Actions, GitHub Pages

## 🚀 Quick Start (Local Development)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rajkumarpawar07/rajkumarpawar07.github.io.git
   cd rajkumarpawar07.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
